3. Interpret an existing PVS library; extract an admissible SAL machine.
4. Prove safety, inspect a counterexample, and exercise the refusal checks.

* The semantic contract includes terminal states

#+begin_src pvs
SAL_Transition_System[S: TYPE,
  initial: [S -> bool], step: [S, S -> bool]]: THEORY
#+end_src

A state is reachable when a *finite prefix* starts in =initial=, follows
=step=, and ends there.

#+begin_src pvs
invariant(p: [S -> bool]): bool =
  FORALL (s: S): reachable(s) IMPLIES p(s)

deadlock_free: bool =
  FORALL (s: S): reachable(s) IMPLIES
    EXISTS (t: S): step(s, t)
#+end_src

Safety sees a reachable terminal state. Progress is a separate obligation.

* The proof rule binds one theorem to one extraction

Before invoking SAL, the rule requires:

1. The registered, typechecked declaration and its original singleton goal.
2. Unchanged PVS/SAL sources and SAL configuration.
3. Complete native TCC proofs, including interpretation obligations.
4. An admitted backend and an exact semantic result.

An expanded/altered goal, a stale import, a modified generated SAL file,
unknown output or an approximation warning leaves the goal open.

First extraction inherits native PVS freshness checks, supplemented by a
stored digest when available. After registration, exact content snapshots apply.

* Define SAL types as sets

#+begin_export latex
\[
\begin{aligned}
 \lbrack\!\lbrack{}\{x:T\mid p\}\rbrack\!\rbrack{}_\eta
   &=\{v\in\lbrack\!\lbrack{}T\rbrack\!\rbrack{}_\eta\mid\lbrack\!\lbrack{}p\rbrack\!\rbrack{}_{\eta[x\mapsto v]}=\mathrm{true}\},\\[2mm]
 \lbrack\!\lbrack{}A\times B\rbrack\!\rbrack{}_\eta&=\lbrack\!\lbrack{}A\rbrack\!\rbrack{}_\eta\times\lbrack\!\lbrack{}B\rbrack\!\rbrack{}_\eta,\\[2mm]
 \lbrack\!\lbrack{}[A\to B]\rbrack\!\rbrack{}_\eta
   &=\{f:\lbrack\!\lbrack{}A\rbrack\!\rbrack{}_\eta\to\lbrack\!\lbrack{}B\rbrack\!\rbrack{}_\eta\}.
\end{aligned}
\]
#+end_export

Records are labelled products; arrays are functions with *exact domains*.
Application outside the domain is undefined in the source semantics.

Type predicates must themselves be well formed. An empty subtype is allowed;
introducing a required witness adds a nonemptiness obligation.

#+begin_export latex
\democaption{Source analogue of Definition 17, p. 27. Scope: resolved, nonrecursive
pure core with explicitly matched primitive meanings.}
#+end_export

* Preserve the domain when removing refinements

Let $\mu(T)$ be the maximal carrier and $\pi_T$ its membership predicate.

#+begin_export latex
\[
\begin{aligned}
 \mu(\{x:T\mid p\})&=\mu(T),
 &\pi_{\{x:T\mid p\}}(v)&=\pi_T(v)\land p[v/x],\\
 \mu([A\to B])&=[A\to\mu(B)],
 &\pi_{[A\to B]}(f)&=\forall a:A.\ \pi_B(f(a)).
\end{aligned}
\]
\[
 \lbrack\!\lbrack{}T\rbrack\!\rbrack{}=\{v\in\lbrack\!\lbrack{}\mu(T)\rbrack\!\rbrack{}\mid\pi_T(v)\}.
\]
#+end_export

For an array indexed by =[1..N]=, the maximal type still has that domain.
Erasing it to all integers would change the model.

#+begin_export latex
\democaption{Definitions 10 and 12, pp. 21, 23; Proposition 3.9, pp. 27--28.
Carrier lemma: structural induction on source types.}
#+end_export

* A sound and complete subtype condition

For well-formed $S,T$ with a common maximal carrier:

#+begin_export latex
\[
 \boxed{\lbrack\!\lbrack{}S\rbrack\!\rbrack{}\subseteq\lbrack\!\lbrack{}T\rbrack\!\rbrack{}
 \quad\Longleftrightarrow\quad
 \models\ \forall v:\mu(S).\ \pi_S(v)\Rightarrow\pi_T(v)}
\]
#+end_export

*Proof.* Rewrite membership on both sides with the carrier lemma.
The left side then says precisely that every value satisfying $\pi_S$
also satisfies $\pi_T$.

This is *semantic relative completeness*: a validity oracle would settle
every compatible subtype check. It is not completeness of PVS proof search.

Different maximal carriers first need the report's compatibility and
type-equivalence obligations, or an explicit representation correspondence.

* Commands: relation and source typing are separate

#+begin_export latex
\[
 R_{g,x,e}(s,t)\equiv g(s)\land t=s[x\mapsto e(s)].
\]
\[
 \operatorname{VC}_{x:=e}\equiv
 \forall s:\mathrm{TypedStore}.\quad
 g(s)\Rightarrow e(s)\in\lbrack\!\lbrack{}T_x\rbrack\!\rbrack{}.
\]
#+end_export

Also check the guard itself, RHS definedness and assignment addresses.
Each deterministic assignment is checked independently.

For =x' IN {y:A | p}=, values come from the *intersection* of the target
type with the offered set. This does not require all offered values to fit,
or promise any successor.

The obligations quantify over all typed states, including unreachable ones.

* Exactness of the source-core VC system

Define =LocalSafe= using independent source evaluation: all typing sites
denote and satisfy their required types under their lexical paths.

#+begin_export latex
\[
 \boxed{\operatorname{LocalSafe}_S(C)
 \quad\Longleftrightarrow\quad
 \models_S\operatorname{VC}_S(C)}
\]
#+end_export

*Scope:* structurally compatible types, resolved acyclic declarations,
pure nonrecursive expressions, exact function domains and matched primitives.

*Proof:* mutual structural induction. Application uses domain membership;
IF splits on its test; assignment uses the carrier lemma; choice checks
each arm; N-ary composition universally quantifies the component conditions.

* Relate the SAL core to the PVS set semantics

Let $E$ be the shallow translation; $\rho$ renames fields and lifts
corresponding values to products and exact-domain functions.

#+begin_export latex
\[
 \rho_T\bigl[\lbrack\!\lbrack{}T\rbrack\!\rbrack{}_S\bigr]=M_P(E(T)),\qquad
 \rho_T(\lbrack\!\lbrack{}e\rbrack\!\rbrack{}_S)=M_P(E(e)).
\]
\[
 \operatorname{LocalSafe}_S(C)
 \quad\Longleftrightarrow\quad
 \models_P E(\operatorname{VC}_S(C)).
\]
#+end_export

Structural induction proves preservation for well-formed types and locally
safe expressions, assuming capture avoidance and primitive correspondence.

Sound PVS proofs of these obligations imply source-local type safety.
Validity does not imply provability or automatic discharge.

* The checked semantic core uses unrestricted stores

#+begin_src pvs
Store: TYPE = [I -> V]
typed(s: Store): bool = FORALL (j: I): ok(j, s(j))

atom(i: I, g: [Store -> bool], e: [Store -> V])
    (s, t: Store): bool =
  g(s) AND t = s WITH [(i) := e(s)]
#+end_src

=ok= is an arbitrary predicate. The successor store is not restricted to
already-typed values, so the preservation theorem can detect a bad update.

The abstract functions =g= and =e= are total. Source guard/RHS definedness
must be established before applying this theorem to an elaborated command.

* A mechanized assignment theorem and composition laws

#+begin_export latex
\[
 \operatorname{preserves}(R)\equiv
 \forall s,t.\ \operatorname{typed}(s)\land R(s,t)
                        \Rightarrow\operatorname{typed}(t).
\]
\[
 \operatorname{preserves}(\operatorname{atom}(i,g,e))
 \ \Longleftrightarrow\
 \forall s.\ \operatorname{typed}(s)\land g(s)
                        \Rightarrow\operatorname{ok}(i,e(s)).
\]
#+end_export

Choice preservation reduces to preservation of every arm. Indexed local
obligations quantify over all component indexes. Simultaneous pointwise
updates are sound when each owned coordinate satisfies its predicate.

The synchronous converse is not claimed: a blocked peer can hide an unsafe
local update. These lemmas use ordinary PVS proofs, without the SAL rule.

* What remains to prove about the implementation

1. Resolution/export/normalization preserves source occurrences and contexts.
2. The renderer preserves carriers, primitive meanings, binding and imports.
3. Native TCCs, including trivial/subsumed ones, realize exactly the core VCs.
4. Semantic extensions and theory interpretations meet their own obligations.

Under those premises, completed sound PVS proofs imply source-local typing.
The subtype equivalence also gives semantic relative completeness.

The corpus tests and the checked update laws support this work; they do not
establish all four premises for every SAL feature.

* Type safety does not settle progress or reachability

- An unreachable =x = 2 --> x' = 3= still fails local typing for =x:[0..2]=.
- An impossible typed initial relation can hide an invalid initializer.
- A synchronous deadlock can mask a component's invalid update.
- Well-typed algebraic equations need not have a solution, or a unique one.

Keep initialization feasibility, deadlock freedom and algebraic-loop
contracts separate from predicate-subtype correctness.
